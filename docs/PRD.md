# 修图对照与批注 Web 应用 PRD

版本：v0.1｜日期：2026-10-19｜状态：需求提案，可用于拆分设计与开发任务

建议产品名称：对照修图

建议项目仓库名称：`retouch-review`

命名说明：Retouch 表示照片后期修饰，Review 表示对比、审阅与反馈。名称覆盖后续版本验收与协作场景；未检查仓库、域名或商标可用性。

## 1. 产品定位

一个面向照片委托人与后期修图师的 Web 审阅工具。用户并排查看原图和修图，在任意一侧放大、平移、圈点，两侧同步展示对应区域；把修改意见绑定到图片位置，生成可回放、可导出的反馈。

核心价值：让“哪里不满意、要改成什么样、改完是否合格”能够被准确传达和逐条验收。

### 1.1 用户已明确的需求

| 需求 | 产品行为 |
| --- | --- |
| 原图与修图同时查看 | 默认左原图、右修图，清晰标注图片与版本 |
| 一侧放大，两侧同步 | 任意一侧操作，两侧定位到相同内容区域 |
| 一侧平移，两侧同步 | 共用观察位置，避免分别寻找同一部位 |
| 圈点与批注 | 圈出问题区域、添加说明，两侧联动显示 |
| 可以回放 | 播放检查过程与批注讲解，支持暂停、跳转和速度调整 |
| 可以导出 | 导出对比图片、反馈文档、离线回放和可继续编辑的项目文件 |

### 1.2 本稿采用的默认决策

- 桌面浏览器优先，鼠标与触控板均可操作；手机首版侧重阅读和回放。
- 首版以本地处理为主，导入图片无需上传服务器，无需登录。
- “回放”包含两种：按批注生成的讲解回放，以及用户主动录制的审阅操作回放。
- 首版通过导出文件向后期交付；在线分享、多人协作列入后续版本。
- 不替用户自动判断修图好坏，不在本工具中直接磨皮、液化或调色。

## 2. 典型使用场景

1. 收到一批精修照片，与原图配对导入。
2. 放大脸部、头发、衣服与背景，检查皮肤质感、边缘、色彩及变形。
3. 圈出脸颊，写下“保留皮肤纹理，减轻磨皮”；在背景标记“移除这处杂物”。
4. 自动生成批注讲解回放，或主动录下自己的检查顺序。
5. 导出 PDF 给后期快速阅读，附带离线回放文件供其查看细节。
6. 收到修改版后逐项复核，保留通过项，重开未解决项。

## 3. 核心业务流程

创建项目 → 导入原图和修图 → 确认配对 → 检查对齐 → 同步对比 → 圈点批注 → 预览回放 → 导出反馈 → 新版复核。

任何阶段都可保存项目包，下次导入继续编辑。

### 3.1 页面组成

| 页面/区域 | 主要内容 |
| --- | --- |
| 项目页 | 新建、恢复本地项目、导入项目包、项目最近保存时间 |
| 图片配对页 | 原图列表、修图列表、自动配对建议、手动确认、缺失提示 |
| 对比工作台 | 顶部工具栏、左右画布、批注侧栏、底部照片列表 |
| 回放面板 | 播放、暂停、进度、速度、章节、录制状态 |
| 导出面板 | 导出范围、格式、分辨率、包含内容、文件大小预估 |

工作台建议布局：顶部放项目名、保存状态和导出；中部双画布占主要空间；右侧展示批注；底部用于切换照片和展开回放时间轴。支持收起侧栏，增大对比面积。

## 4. 图片导入与配对

### 4.1 首版能力

- 支持拖入或选择 JPEG、PNG、WebP；不支持的格式在导入前明确提示。
- 可分别批量导入“原图”和“修图”，也可对单张图片手动配对。
- 按文件名提出配对建议。后缀清理规则只用于建议；出现多候选时必须手动确认，不静默配错。
- 显示文件名、像素尺寸、文件体积、缩略图和配对状态。
- 导入时统一照片方向，后续坐标基于方向校正后的图片。
- 缺少任一侧图片时，可以补图，但不可将该组标记为已完成对比。
- 同一原图可追加多个修图版本；首版支持选择当前审阅版本，保留已有版本及其批注。

### 4.2 边界

- RAW、PSD、分层 TIFF 和 HEIC 不作为首版承诺，提示用户先转成支持的格式。
- 不拉伸图片强行填满窗口；保留宽高比，空白区域采用中性背景。
- 批量导入遇到损坏图片时，单独报告失败项，允许其他图片继续导入。

## 5. 同步对比：核心交互规格

### 5.1 同步观察

默认开启“同步视图”。在任意一侧缩放或平移，另一侧同步到对应的图像内容；窗口尺寸变化后仍保持观察位置。

| 动作 | 规则 |
| --- | --- |
| 滚轮/触控板缩放 | 围绕操作侧指针所指的图像位置缩放，对侧保持对应位置 |
| 平移 | 手形工具拖动；使用绘图工具时按住空格临时平移 |
| 适应窗口 | 两侧恢复完整照片视图 |
| 查看原始像素 | 以当前操作侧图片为基准进入 100%，对侧保持内容尺度一致并显示各自比例 |
| 暂停同步 | 允许独立平移和缩放；重新开启时绑定两侧当前的位置与缩放比例，不跳动或覆盖任一侧，后续操作按此关系双向联动 |
| 定位批注 | 点击列表条目，两侧共同定位该区域并高亮相同编号 |
| 对应位置提示 | 可显示同步十字光标，辅助观察细节；可关闭 |

需要明确：两张图片分辨率不同时，“对应内容一样大”与“两侧都为原始像素 100%”不能总是同时成立。同步模式优先保证内容尺度一致，分别显示缩放比例。

### 5.2 裁切、旋转和液化的处理

- 同构图、不同分辨率：通过归一化坐标关联同一位置。
- 裁切、平移、旋转或统一缩放：提供手动对齐模式，保存两张图的坐标映射；不修改源文件。
- 比例不一致时提示检查对齐；比例一致也允许用户主动打开对齐工具。
- 对齐模式可用半透明叠加辅助调整，确认后才能用于准确的跨图圈点。
- 液化、局部变形等无法用全局变换精确对齐：默认标记为近似对应，允许为同一批注分别指定两侧区域。
- 对应位置落到裁切范围之外时，显示“该区域在此版本中不可见”，不把标记挤到图片边缘。
- 已有批注后修改对齐参数，要求预览影响；保留批注的原始锚点，支持撤销。

### 5.3 补充对比方式

- 首版必需：左右并排。
- 首版辅助：对齐模式下的透明度叠加。
- 后续增强：拖动分割线对比、同位置原图/修图闪切、自由透明度叠加。
- 差异热力图列为后续实验功能；压缩、调色和轻微错位都可能产生差异，不能直接作为修图缺陷判定。

## 6. 圈点与批注

### 6.1 标记工具

首版提供点标记、矩形、椭圆、自由圈画；所有标记均为独立图层，不写入原图。

- 从任意一侧创建批注，在另一侧展示映射后的对应标记，共用编号和文字。
- 单条批注可附多个区域，用于表达“左右两边保持一致”等反馈。
- 支持选中、移动、调整大小、删除、撤销和重做。
- 提供“隐藏全部标记”，方便看净图；恢复后批注不丢失。
- 笔触粗细和编号尽量保持屏幕可读，区域几何随图片缩放。
- 绘图与平移工具明确区分，避免用户拖动画面时误画。

### 6.2 批注内容

| 字段 | 规则 |
| --- | --- |
| 编号 | 图片内唯一，删除后不复用，便于导出和沟通 |
| 修改说明 | 必填，例如“脸颊磨皮过重，请恢复部分纹理” |
| 分类 | 可选：皮肤、五官、体形、头发、服装、背景、色彩、其他 |
| 优先级 | 默认普通，可选必须修改、建议调整 |
| 状态 | 待修改、待复核、已通过；未通过可退回待修改 |
| 区域 | 可为空，允许添加“整体肤色偏黄”等全图意见 |
| 版本 | 必须绑定被审阅的修图版本，避免新版覆盖旧版反馈 |
| 时间 | 创建时间、最后更新时间 |

画完后立即进入文本输入。取消空白批注时一并移除临时图形。点击批注卡片可编辑文字并定位区域；编辑中的草稿自动保留。

## 7. 回放

### 7.1 模式 A：批注讲解回放（首版必需）

目的：让后期按顺序理解修改意见，无需观看冗长的鼠标操作。

1. 按照片顺序及用户调整后的批注顺序生成播放列表。
2. 进入每张照片先展示全图，再定位到批注区域。
3. 两侧同步放大，高亮标记，并显示完整修改说明。
4. 默认每条停留 5 秒，可单独调整；长文字可暂停阅读。
5. 无区域的批注使用全图视角；有多个区域时以覆盖全部区域的视角展示。
6. 无批注照片默认跳过，可勾选纳入回放。

此模式由当前批注生成，不要求提前录制，也不宣称复现历史操作。

### 7.2 模式 B：审阅操作回放（首版后半阶段）

用户点击“开始录制”后，记录切换照片、缩放、平移、圈画、批注确认以及显示/隐藏标记等操作；支持暂停录制、继续和结束。

- 录制期间显示明显状态和计时，不默认记录用户全部使用过程。
- 保存结构化事件和初始快照，以便在不同窗口尺寸下重建双画布。
- 文字仅记录确认后的内容，不记录逐字键入。
- 连续平移和缩放合理采样，回放时插值；绘制过程记录轨迹。
- 保留原始事件时间，默认跳过超过 3 秒的无操作等待，也可选择原速重放。
- 保存录制开始时的图片版本、对齐参数和批注快照。后续编辑不改变历史录制；可重新录制生成新记录。
- 首版不含麦克风录音、摄像头或桌面录屏。

### 7.3 两种回放共用控制

- 播放/暂停、上一条/下一条、拖动进度、重新播放。
- 支持 0.5×、1×、1.5×、2×速度。
- 章节列表按照片与批注组织，点击直接跳转。
- 拖动进度后必须准确重建该时刻的画布和标记，不能仅改变计时文字。
- 播放时为只读；暂停后可临时观察，继续时恢复回放视角。
- 支持全屏，展示照片名、修图版本和当前意见。
- 尊重减少动态效果偏好，可直接切换视角而不播放移动动画。

## 8. 导出

### 8.1 格式与范围

| 导出格式 | 用途 | 必须包含 |
| --- | --- | --- |
| PNG 对比图 | 发给后期快速沟通 | 左右对比、原图/修图标签、版本、编号、可选文字说明 |
| PDF 反馈单 | 批量正式交付 | 项目摘要、逐图概览、局部放大对比、完整批注、状态与优先级 |
| 离线 HTML 回放 | 无需安装即可交互查看 | 双画布、图片、标记、文字、时间轴、播放控制 |
| 可编辑项目包 | 备份、换电脑、继续修改 | 图片资源、版本、对齐参数、批注、录制事件和格式版本 |
| 视频 | 手机聊天直接观看 | 后续增强：将回放渲染成视频，具体编码格式经兼容性验证后确定 |

导出范围支持当前照片、选定照片、整个项目；反馈内容支持全部批注或仅未通过项。导出前显示预览、数量、预计体积和所用版本。

### 8.2 输出要求

- PNG 可选择当前视野或完整照片；局部反馈可附全图定位缩略图。
- PDF 长批注自动换页，不裁掉文字；页眉或页脚可追溯图片名、版本和编号。
- 离线 HTML 单文件内嵌所需脚本和图片，不依赖服务器、网络字体或 CDN；首次打开不要求安装应用。
- HTML 按静态文本渲染文件名和批注，不把用户输入当作可执行代码。
- 大项目的 HTML 支持按照片拆分，提供体积预估；不能静默降质或漏图。
- 可编辑项目包需包含资源清单和校验信息；导入后恢复版本、批注、对齐关系和回放。损坏或格式过新时明确报错。
- 图片导出前允许选择分辨率或质量，明确显示结果像素尺寸；放大输出不代表增加真实细节。
- 导出任务展示进度、允许取消；失败时保留项目和批注，可重试。
- 导出 PDF/PNG 主要用于沟通，不能替代源文件的精细色彩验收；浏览器和查看器的色彩表现需要实测。

## 9. 多轮修图与复核

- 原图保持不变；修图采用 V1、V2 等版本记录，追加版本不覆盖历史文件。
- 新版默认新建审阅上下文，旧版批注保留。
- 可将未通过意见复制到新版作为待复核项，保留来源批注 ID；所有继承区域标记为待检查定位，不自动宣称准确。
- 只有用户主动确认，批注才变为“已通过”。
- 单张照片在没有未完成意见后可标记通过；无批注照片也需主动确认，不能自动算通过。
- 后续支持 V1 与 V2 直接对比、版本序列回放，以及修图师回复。

## 10. 保存与隐私

- 本地自动保存项目元数据、图片和批注，显示“保存中/已保存/保存失败”。
- 刷新或关闭后可恢复已保存内容；浏览器清理数据可能移除本地项目，因此提供显著的项目包备份入口。
- 存储空间不足时明确提示并保留当前可恢复数据，提供导出备份路径，不显示虚假的“保存成功”。
- 首版图片默认不上传；未来在线分享必须由用户主动触发。
- 分享导出件默认移除可去除的定位等 EXIF 信息；完整项目包可能包含原始文件及元数据，在导出选项中说明。
- 删除项目可撤销或二次确认；删除某版本前说明它关联的批注与回放。

## 11. 性能与兼容性验收目标

以下为开发目标，需用固定测试设备和样片验证后才能作为已实现能力。

- 参考规模：单项目 50 组照片，每张不超过 30 MB、2400 万像素；超过时先提示资源风险，允许分批导入。
- 以当前照片与相邻照片按需解码，避免一次性解码整批大图；预览与原始细节按需加载。
- 当前照片加载完成后，同步缩放与平移争取达到稳定 30 FPS 以上；对侧视觉更新延迟目标不超过 100 ms。
- 首版桌面验收覆盖当期 Chrome、Edge、Safari；具体版本记录在测试报告中。
- 手机端必须能阅读批注、切换照片和播放讲解；复杂圈画编辑作为后续优化。
- 验收必须包括不同图片尺寸、宽高比、方向、色彩描述文件、损坏文件和低存储空间。
- 超大图片解码失败时说明限制，允许换图或降采样预览；降采样状态必须可见。

## 12. 核心数据对象

| 对象 | 核心内容 |
| --- | --- |
| Project | 名称、创建时间、保存时间、照片顺序、格式版本 |
| PhotoPair | 原图资源、修图版本列表、当前版本、审阅状态 |
| ImageAsset | 原始文件、尺寸、方向、格式、内容校验信息 |
| RetouchVersion | 版本 ID、图片资源、版本名称、创建时间 |
| Alignment | 图片关系、变换参数、人工确认状态 |
| Annotation | 稳定 ID、编号、绑定版本、说明、分类、优先级、状态、来源批注 |
| AnnotationRegion | 所属批注、来源图片、形状、归一化坐标、对侧可选独立锚点 |
| Replay | 模式、照片顺序、批注顺序、停留时长、资源及状态快照 |
| ReplayEvent | 相对时间、事件类型、相机状态或图形内容 |

坐标必须基于图像内容，而不是浏览器屏幕像素。视图变换、图片对齐和批注区域分开保存；调整窗口尺寸不得改变批注实际位置。

## 13. 分期建议

### P0-A：完成日常审阅与交付

图片批量导入及配对、双图同步缩放和平移、手动对齐、圈点批注、版本保留、本地保存、批注讲解回放、PNG/PDF 导出、可编辑项目包。

### P0-B：补齐完整回放交付

主动录制操作、事件时间轴、历史回放快照、离线 HTML 回放导出、大项目拆分导出、桌面与手机播放验收。

P0-A 和 P0-B 一起构成本需求的首版完整交付；不能仅有静态截图就声称完成回放与导出。

### P1：协作与效率增强

在线链接分享、访问控制、修图师回复、版本间直接比较、自动对齐辅助、分割线/闪切模式、回放视频导出。

### 暂不纳入

直接修图、AI 自动美容、专业 RAW 显影、多人实时共同编辑、商业支付与会员体系。

## 14. 关键验收用例

## 15. 交付完成定义

用户能够独立完成一批照片的导入、配对、同步对比、圈点、写意见、生成或录制回放，并导出反馈。接收方无需开发环境即可阅读 PDF 和操作离线回放；用户可通过项目包恢复编辑并复核新版。以上流程均应使用真实照片完成验证。

## 16. 已确认交互调整（2026-10-19）

- 白色主题，图片对比为页面主要功能；压缩标题、工具与底部信息，画布占据剩余窗口空间。
- 批注面板和照片列表默认折叠，用户可随时展开。
- 默认触控板模式：双指滑动平移、捏合缩放；提供鼠标模式用于滚轮缩放。
- 触屏支持双指平移和缩放，进入双指手势时取消尚未完成的单指圈画，避免误批注。
- 缩放围绕手势位置生效，按动画帧合并绘制，不因每个事件重新分配画布像素缓冲。

## 17. 批注联动与单图查看（2026-10-19）

- 点击画布上的批注编号、圈选区域或自由圈画线条，自动展开旁边的批注面板，定位并高亮对应卡片；清除可能隐藏该卡片的筛选。
- 拖动超过点击阈值不打开卡片，双指手势不误触卡片。
- 提供“对比 / 仅原图 / 仅精修”切换，单图占满画布，保留观察位置及批注数据。

## 18. 导出筛选与执行反馈（2026-10-25）

- 导出范围增加“仅含批注的照片”，按当前修图版本及所选批注范围筛选；选择“仅未通过”时排除仅有已通过批注的照片。
- 导出弹窗内显示准备、绘制、编码、PDF 页码或打包进度，完成后提示查看浏览器下载列表；无符合条件的照片、失败、取消均在弹窗内反馈。
- PDF 分页编码并在页间让出界面执行时间；PNG 单张生成及多张打包均更新进度。取消后不下载结果，保留源图和批注。
- 可编辑项目包仍为完整备份，历史录制仍保持完整快照，明确说明不受照片筛选影响。

## 19. 快速浏览有批注的照片（2026-10-25）

- 照片列表旁提供“有批注照片”切换入口；开启后展开照片列表，只显示当前修图版本含批注的照片，包括批注已通过的照片。
- 若当前照片不符合筛选，开启时切换到第一张符合条件的照片，并在桌面展开批注面板；手机保留面板开关状态，避免遮挡浏览。再次点击恢复全部照片。
- 列表显示筛选数量，上一张/下一张按筛选后的照片顺序切换，不再逐张跳过无批注照片。没有结果时显示明确空状态。
- 编辑或切换版本后更新筛选结果；筛选不修改项目内容，也不改变导出筛选。

## 20. PDF 去除重复全图页（2026-10-25）

- 有批注的照片直接导出各条批注的局部对照与完整说明，不再在前面重复插入全图概览页。
- 无批注照片若在导出范围内，仍保留一页全图对照；长批注续页只继续文字，不重复图片。
- 详情页明确标示左侧原图、右侧修图。
